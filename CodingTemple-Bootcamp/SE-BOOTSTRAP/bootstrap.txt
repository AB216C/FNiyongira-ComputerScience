
🚀 Benefits of Using Bootstrap
Responsive Design: Bootstrap's grid system ensures your website automatically adjusts its layout to fit phones, tablets, and desktops.
Pre-Built Components: It includes CSS for buttons, navigation bars, forms, and more.
Faster Development: You don’t need to write all the CSS yourself — just add the Bootstrap classes.
Consistent Look: Bootstrap ensures your design looks the same across different browsers (like Chrome, Safari, Firefox).


🔗 How to Include Bootstrap in Your Project
There are two ways to include Bootstrap in your project: using a CDN or installing it locally. 

Option 1: Using a CDN
To use Bootstrap in your HTML file without downloading it, you can link to Bootstrap’s CSS using a "CDN" (Content Delivery Network). This is a URL that lets your webpage load Bootstrap from the web.



Add this link inside the <head> of your HTML file:

<link href="https://stackpath.bootstrapcdn.com/bootstrap/4.5.2/css/bootstrap.min.css" rel="stylesheet">
This link will bring Bootstrap’s styles into your webpage. We will also cover a quick and easy way to use an extension for this method. 
<head>
  <link rel="stylesheet" href="css/bootstrap.min.css">
</head>
<body>
  <!-- Your page content here -->
  <script src="js/popper.min.js"></script>
  <script src="js/bootstrap.min.js"></script>
</body>

Option 2: Installing Bootstrap Locally
If you want to install Bootstrap and use it from your local files, you can download it to your project folder and link to the downloaded files. 
This method is useful if you’re working offline or prefer to have all assets in your project.



Steps to Install Bootstrap Locally:

Download Bootstrap:
Go to the Bootstrap Download page.https://getbootstrap.com/

Download the compiled CSS and JS files by clicking "Download".
Add Bootstrap Files to Your Project:
Extract the downloaded zip file.
Move the bootstrap.min.css file to a css folder inside your project.
Move the bootstrap.min.js and popper.min.js files to a js folder inside your project.

Link Bootstrap in Your HTML:
In your HTML file, link to the Bootstrap CSS and JS files you added to your project.
<head>
  <link rel="stylesheet" href="css/bootstrap.min.css">
</head>
<body>
  <!-- Your page content here -->
  <script src="js/popper.min.js"></script>
  <script src="js/bootstrap.min.js"></script>
</body>

📐 What is the Bootstrap Grid System?
Bootstrap is powerful because of its grid system. Think of it as combining the flexibility of CSS Grid and Flexbox with a library of pre-designed components.
 The grid system is one of the core features of Bootstrap that helps you organize content into rows and columns.

A webpage layout in Bootstrap is divided into 12 equal-width columns, which allows you to control how much space each section of your content occupies. 
This layout system provides flexibility for responsive design, ensuring your webpage adapts to different screen sizes.


🧱 The Structure of a Bootstrap Grid
In Bootstrap, the grid system relies on three essential elements: containers, rows, and columns. This structure ensures that your content is well-organized and responsive across different devices. Let’s break down the general format:

<div class="container">
  <div class="row">
    <div class="col">
      <p>Content</p>
    </div>
  </div>
</div>
1. container:

The container is the outermost wrapper for your content. It ensures that the layout is properly aligned and spaced on the page.
Purpose: Adds margins and padding on both sides of the screen to center your content. Containers also provide responsive behavior, ensuring your layout adjusts to different screen sizes.
2. row:

A row divides your layout into horizontal sections.
Purpose: Rows ensure that the columns inside them align properly. They also clear any floating elements, which keeps your layout intact.
Important: Rows must always be placed inside a container and act as wrappers for the columns.
3. col:

A column holds your actual content.
Purpose: Columns allow you to divide the space inside a row. In Bootstrap, the columns inside each row should add up to a total of 12 columns (but you don't have to use all 12 every time).


Example Breakdown:

Container: Wraps everything to align the layout on the screen.
Row: Creates a new horizontal section for columns.
Column: Holds the content inside the row. Multiple columns in a row will divide the space equally or according to the sizes you assign.
Columns 
🔄 Auto-Resizing Columns
By default, columns in a row will automatically adjust to evenly fill the available space, without needing to specify exact sizes. This makes it quick and easy to build balanced layouts.



In the example below, we have three columns. Since there are 12 total columns in the grid, each col will automatically take up 4 columns (12 divided by 3 equals 4), distributing the available space evenly.

<div class="container">
  <div class="row">
    <div class="col">
      Column 1
    </div>
    <div class="col">
      Column 2
    </div>
		<div class="col">
      Column 3
    </div>
  </div>
</div>
Tip: Bootstrap will automatically resize columns based on the number of columns in the row to ensure everything fits neatly.
🧩 Assigned Column Sizes
In some cases, you may want to control exactly how much space a section should take up by assigning column sizes. You can use classes like col-6 or col-4 to specify how many of the 12 available columns an element should span.

In the example below, we want to split the page into two equal sections, so each section takes up 6 columns (col-6), since 6 + 6 equals 12.

Screenshot 2024-10-18 at 1.08.49 PM.png
<div class="container">
  <div class="row">
    <div class="col-6">This takes up half the width</div>
    <div class="col-6">This takes up the other half</div>
  </div>
</div>
Remember: The total number of columns in any row should not exceed 12. If the columns don't add up to 12, Bootstrap will adjust them to fit the layout.



🎯 Understanding Column Spanning
When we say a column spans multiple columns, we mean that it takes up a specific number of slots out of the 12 available in the row.

How Spanning Works:
col-3: Spans 3 out of 12 columns (or one-quarter of the row width).
col-4: Spans 4 out of 12 columns (or one-third of the row width).
col-6: Spans 6 out of 12 columns (half the row width).
Example: If a column spans 3 columns, it occupies 3 out of the 12 slots, leaving 9 slots for other columns to fill.
