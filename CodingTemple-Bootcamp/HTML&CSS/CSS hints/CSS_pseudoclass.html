COMMON PSEUDO CLASSES

:hover - Applies styles when the user hovers over an element. // This makes links turn red and underlined when a user hovers over them. css a:hover { color: red; text-decoration: underline; }

:active - Applies styles when an element is in an "active" state, such as when a button is clicked. // This changes the button color when it is being clicked. css button:active { background-color: darkblue; }

:focus - Applies styles when an element, like an input field, is focused (usually when clicked or navigated to using the keyboard). // This styles an input field’s border when it is in focus. css input:focus { border-color: blue; outline: none; }

:first-child - Applies styles to the first child element within a parent element. // This makes the first paragraph within any container bold. css p:first-child { font-weight: bold; }

:last-child - Targets the last child of a parent element. // This removes the bottom margin of the last paragraph in a container. css p:last-child { margin-bottom: 0; }
